# Dataset

This project uses the Kaggle dataset **Astana Real Estate Dataset** by `turarr`.

Dataset link: https://www.kaggle.com/datasets/turarr/astana-real-estate-dataset

The CSV file is intentionally not committed to this repository. To run the notebook:

1. Download the dataset from Kaggle.
2. Place `astana_real_estate_dataset.csv` in the repository root.
3. Run `notebooks/astana_housing_endterm.ipynb` from the repository root.

The file must retain the expected name: `astana_real_estate_dataset.csv`. It is
not included in Git and no synthetic replacement is used. The endterm notebook
stops with a clear prerequisite error if this official file is unavailable.

This keeps the repository safer for public GitHub use because the dataset remains distributed through its original Kaggle page and terms.
