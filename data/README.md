# Data directory

The notebook obtains **Astana Real Estate Dataset** by `turarr` from an attached
Kaggle input, an optional local CSV, or KaggleHub. The source is a Kaggle
collection of Krisha.kz listings, not an official government dataset. Before
publishing or redistributing a CSV copy, check its licence and terms.

Dataset page: https://www.kaggle.com/datasets/turarr/astana-real-estate-dataset

The first automatic download outside Kaggle needs internet access. No local CSV
is required and no synthetic replacement is used.
