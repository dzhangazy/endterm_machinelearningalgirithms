# Data directory

Do not commit the Kaggle CSV here unless its licence and redistribution terms
explicitly permit it. Download **Astana Real Estate Dataset** by `turarr` from
https://www.kaggle.com/datasets/turarr/astana-real-estate-dataset and place
`astana_real_estate_dataset.csv` in the repository root, as required by the
notebooks.

This folder exists to document the data boundary; it contains no replacement
or synthetic data.
